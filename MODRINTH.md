# HexCast NEOFORGED

**A NeoForge 1.21.1 port of Hex Casting — draw patterns to cast powerful, programmable magic.**

---

## EN — Description

**HexCast NEOFORGED** is a port of the beloved **Hex Casting** mod (by petrak@) to **NeoForge 1.21.1**. Inspired by PSI, this mod lets you cast spells by drawing patterns on the fly. No two hexes need be alike — mix, match, and program your own magical effects.

### Features
- Draw unique patterns to cast spells in real-time
- Programmable magic system with 150+ actions
- In-game book (Patchouli) with full documentation
- Circle casting for advanced rituals
- Staffs, lenses, trinkets and more magical items
- Brainsweeping, quenched allays, and other weirdness
- Compatible with JEI, Curios, Create, Farmer's Delight

### Requirements
- **NeoForge 21.1+**
- **PAUCAL**
- **Patchouli**
- **Kotlin for Forge**
- **Caelus Elytra API**

### Optional
- **Curios** — wearable lenses
- **JEI** — recipe viewer integration

## RU — Описание

**HexCast NEOFORGED** — это порт мода **Hex Casting** (автор: petrak@) на **NeoForge 1.21.1**. Вдохновлённый PSI, этот мод позволяет создавать заклинания, рисуя узоры на лету. Ни одно заклинание не обязано повторять другое — комбинируй, программируй и твори собственную магию.

### Возможности
- Рисуй уникальные узоры для мгновенного колдовства
- Программируемая магия: 150+ действий
- Внутриигровая книга (Patchouli) с полной документацией
- Круговые ритуалы для продвинутой магии
- Посохи, линзы, безделушки и прочие магические предметы
- Выманивание разума, гашеные аллеи и прочие странности
- Совместимость с JEI, Curios, Create, Farmer's Delight

### Требования
- **NeoForge 21.1+**
- **PAUCAL**
- **Patchouli**
- **Kotlin for Forge**
- **Caelus Elytra API**

### Опционально
- **Curios** — носимые линзы
- **JEI** — просмотр рецептов
